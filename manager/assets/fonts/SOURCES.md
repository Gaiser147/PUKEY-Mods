# Interface fonts

Amarante Regular and Oswald are used by the game's font inventory and by the selected manager design. These files were downloaded from the official Google Fonts repository, rather than extracted from the game.

- `Amarante-Regular.ttf`: https://raw.githubusercontent.com/google/fonts/main/ofl/amarante/Amarante-Regular.ttf
- `Oswald.ttf`: https://raw.githubusercontent.com/google/fonts/main/ofl/oswald/Oswald%5Bwght%5D.ttf

Both use the SIL Open Font License 1.1. The original license texts are included beside the font files. The application uses an operating-system font for body text.
