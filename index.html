From download to F5 in four steps

The manager does the file work. Each mod installs on its own, so you only add what you want.

  1. Extract and start

    Unpack the whole folder and run the app. Keep _internal beside it.

    PUKEY-Mod-Manager

  2. Find the game

    Let the manager locate the Steam demo, or browse to its folder yourself.

    Find in SteamBrowse…

  3. Install UE4SS

    Close the game. The manager downloads UE4SS from its official release and disables the incompatible example mods.

    Install UE4SS

  4. Choose your mods

    Install a mod, adjust its settings and keys, then start the demo through Steam.

    Install modSave settings

Before you start

What the mods need, and what this project does not promise.

Requirements

  • Windows 10 or 11 with the Steam demo of PUKEY GODDESS SHOT TRICK.
  • UE4SS, which the manager installs from its official release. Manual installs follow the installation guide.
  • Linux and Steam Deck: the manager runs there and manages the Windows game files. Gameplay under Proton is unverified.

Good to know

  • Game or UE4SS updates can require mod changes. The full game has not been tested.
  • No game files are shipped. FamSwap and MovieSwap use images and videos you supply.
  • Updates keep your settings and personal files. Something not working? See troubleshooting.
