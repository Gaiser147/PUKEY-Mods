Mod Manager 0.5

Pick the game folder, install UE4SS, choose your mods. The manager installs, updates and configures FreeCam, LightTools, FamSwap and MovieSwap for the PUKEY GODDESS SHOT TRICK demo.

Windows ZIPLinux x86-64 tar.gzInstall manually

No Python needed. Extract the whole folder and run PUKEY-Mod-Manager. Proton gameplay is unverified.

FreeCam F5Free camera, teleport, five camera bookmarks per map.
LightTools F1–F4Floodlight, headlight, fog, shadows and post-processing.
FamSwap F8Your own still images behind the counter and at the table.
MovieSwap F11Custom MP4 replacements for the game's videos.
