# Surface brief: GitHub Pages site (home + guides)

Scope: `index.html` is the home page (Persuade); `_layouts/default.html` carries every guide rendered from Markdown (Read). Audience: players of the PUKEY GODDESS SHOT TRICK Steam demo arriving from search or a forum link. Job: get the Mod Manager onto their machine, or reach a manual install guide. Proof: the real release, the four real mods and their real keys. Constraints: no original game artwork, screenshots or extracted textures; English copy; GitHub Pages Jekyll with whitelisted plugins only; README stays a plain GitHub README.

## Direction contract

THESIS: The home page is the current Mod Manager release announced on one of PUKEY's smoky dialogue sheets, download in hand; it refuses the README-as-website and the centred-hero-plus-feature-cards page.

OWN-WORLD: Near-black #111012 ground with fine grain; authored smoke sheets (#1a161c, inset rim); mint #02e5a2 torn-edge ribbon for tags, selection and key values; pink #ff0060 torn-edge stroke for the one primary action; Amarante for display, Oswald for labels/keys/actions, system sans for reading text; key chips as dark wells with mint Oswald text.

STORY: Visitor sees the latest manager version, understands it installs and configures four named mods, downloads the build for their OS or follows the manual route, then finds the guide for a mod.

FIRST VIEWPORT: Nav strip (Amarante wordmark left, Oswald links right). One wide smoke sheet below it, ~65% of viewport height; a ghosted Amarante version numeral bleeds off its lower-left edge; right of centre: mint ribbon "Prerelease · date", h1 "Mod Manager <version>", two-line pitch, pink Windows download, Linux and manual-install secondaries, one honest note line. Below the sheet, starting inside the fold: a ruled ledger of the four mods, each with its key chips.

FORM: Release sheet, position 6 of 7 on the grounded list; seed:99a755cf4ecffb37. Signature interaction: the ribbon tag brush-wipes in once on load; hovering or focusing a mod in the ledger fills its key chips with the mint ribbon.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
